## Reversi Multiplayer Game

Othello/Reversi с тремя режимами:

- **Player vs AI** (Easy / Normal / Hard)
- **Local 1v1** (два игрока за одним устройством)
- **Online 1v1** (через Socket.IO: lobby + комнаты)

## Запуск локально

```bash
cd server
npm install
npm start
```

Откройте `http://localhost:3000`.

## Online режим

- В режиме **Online 1v1** открывается лобби со списком активных комнат.
- Можно создать комнату с auto-кодом или ввести собственный код (4-6 символов).
- Можно войти в комнату из списка или вручную по коду.
- После выхода/дисконнекта состояние комнат корректно обновляется на сервере.

## Темы дизайна

Добавлен переключатель дизайна с несколькими общими вариантами:

- **Forest Night**
- **Sunset Wood**
- **Neon Grid**
- **Minimal Light**

Выбранная тема сохраняется в `localStorage`.
